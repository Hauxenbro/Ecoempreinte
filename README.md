# Campus Footprint 🌿⚡️

**Campus Footprint** est une application web conçue pour évaluer rapidement et de manière intuitive l'empreinte carbone individuelle. Le projet permet aux utilisateurs de suivre l'impact écologique de leurs habitudes quotidiennes en transformant la complexité des données climatiques en un outil simple et visuel.

---

## 📌 Fonctionnalités principales

* **Évaluation de l'empreinte carbone** : Formulaire interactif pour calculer votre score écologique personnel.
* **Visualisation des données** : Intégration de graphiques pour afficher clairement les résultats.
* **Interface moderne et intuitive** : Design fluide et adaptatif
* **100 % Gratuit** : Outil accessible rapidement sans inscription complexe.

---

## 🛠️ Technologies utilisées

* **Frontend** : HTML5, CSS3, JavaScript (ES6+)
* **Frameworks et bibliothèques** :
  * [Chart.js](https://www.chartjs.org/) — Génération des graphiques et données visuelles[cite: 4]

## 🚀 Lancement rapide

Ce projet est un site web statique qui ne nécessite aucun environnement serveur spécifique.

1. **Cloner le dépôt** :
   ```bash
   git clone https://github.com/Hauxenbro/Ecoempreinte.git
   cd Ecoempreinte
   ```
2. **Executer**
   `Accueil.html`
